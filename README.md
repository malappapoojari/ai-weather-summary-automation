# 🌦️ AI Weather Summary Automation using n8n & Google Gemini

## 📌 Overview

AI Weather Summary Automation is an intelligent workflow built with *n8n, **Google Gemini AI, **OpenWeather API, and **Gmail*. It automatically fetches real-time weather data, generates an AI-powered summary with personalized recommendations, and sends the results directly to your email.

This project demonstrates workflow automation, API integration, AI-powered text generation, and email automation.

---

## 🚀 Features

- ⏰ Automated execution using Schedule Trigger
- 🌍 Fetches real-time weather data from OpenWeather API
- 🤖 Generates weather summaries using Google Gemini AI
- 👕 Provides outfit recommendations
- 🌳 Suggests outdoor activities based on weather
- 💧 Sends weather reminders and safety tips
- 📧 Automatically delivers the summary via Gmail
- ⚡ Fully automated end-to-end workflow

---

## 🛠️ Tech Stack

- n8n
- Google Gemini AI
- OpenWeather API
- Gmail API
- REST API

---

## 📋 Workflow

1. Schedule Trigger starts the workflow automatically.
2. OpenWeather API fetches the latest weather information.
3. Google Gemini AI analyzes the weather data.
4. AI generates:
   - Weather Summary
   - Outfit Suggestion
   - Outdoor Activity Recommendation
   - Weather Reminder
5. Gmail sends the generated summary to the user's email.

---

## 🔄 Workflow Architecture

Schedule Trigger
      ↓
Fetch Weather Data (OpenWeather API)
      ↓
Google Gemini AI
      ↓
Generate Weather Summary
      ↓
Send Email (Gmail)
